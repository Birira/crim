# Airbnb Dublin - Dashboard

Dashboard interactivo para explorar alojamientos de Airbnb en Dublín, Irlanda. Incluye mapa geográfico, filtros por barrio, tipo de habitación y precio, y visualizaciones de datos.

## Demo

[Ver Dashboard en vivo](https://ntxfdbr2ch9cectnynsnji.streamlit.app)

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app/dashboard.py
```
